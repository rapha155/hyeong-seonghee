# 포트폴리오 전면 수정 기획 (2026-10-19)

## 1. 현재 버전 진단

| 문제 | 근거 |
|---|---|
| 읽는 순서가 없다 | 표지 → 소개 → 목록 → 프로젝트 순이지만, "이 사람이 무엇을 잘하고 어떤 증거가 있나"가 3초 안에 안 보임 |
| 모든 글이 같은 무게 | 제목·본문·수치가 비슷한 크기와 색. 성과 수치(22.9초 → 0.12초 등)가 불릿 속에 묻힘 |
| 핵심 기술 구현이 3단 문단 | 세 칼럼이 모두 Problem/Solution 문단. 훑어 읽기 불가. 결과가 없는 칼럼도 있음 |
| 화면 캡처가 설명 없이 놓임 | 무엇을 봐야 하는지 캡션·표시가 없음. 데스크톱 캡처는 글자가 읽히지 않는 크기 |
| 프로젝트 구조가 균일함 | 업무 프로젝트(팀·역할 경계 중요)와 1인 앱(출시·운영 중요)이 같은 틀. 1인 앱 3개는 2장씩 쓸 내용이 부족 |
| 역할 경계 표기가 약함 | 팀 프로젝트에서 "센서는 팀장 담당"이 본문에 묻혀 있음. 채용자가 가장 먼저 확인하는 항목 |
| 시각 언어 불일치 | 표지만 그라데이션, 나머지는 흰 배경. 배지·칩·구분선 스타일이 장마다 다름 |

## 2. 목표와 독자

- 독자: 채용 담당자(30초), 기술 면접관(3분), 면접 중 화면 공유(발표).
- 읽기 층위
  - 3초: 표지 + "누구인가" 한 줄 + 숫자 3개
  - 30초: 프로젝트 인덱스(카드)에서 분야·역할·성과 파악
  - 3분: 케이스 스터디에서 문제 → 접근 → 결과 확인
- 포지셔닝 문장(초안): **"앱과 웹을 혼자 끝까지 만들어 본 개발자가, 지금은 로컬 LLM·업무 시스템·스마트팜 화면을 만든다."**

## 5. 디자인 시스템 (1280×720 기준)

- 그리드: 12칼럼, 좌우 여백 72, 거터 24, 상하 여백 64.
- 타입 스케일: Display 64 / H1 40 / H2 28 / H3 20 / Body 17 / Caption 14 / KPI 48. 본문 줄 길이 45자 이내.
- 색: 잉크 #111, 본문 #333, 보조 #6b7280, 선 #e5e7eb, 바탕 #fff, 강조 1색(#2f6fed 유지 또는 변경), 강조 연한 면 #eef3fb. 표지·마무리만 어두운 배경.
- 폰트: Pretendard (현재 유지). 영문 숫자는 Pretendard 기본.
- 공통 컴포넌트: 슬라이드 헤더(프로젝트 번호 · 이름 · 장 제목), KPI 타일, 역할 바, 기술 칩, 문제/해결/결과 카드, 화면 캡션, 스토어 배지, 페이지 번호(우하단).
- 접근성: 본문 대비 4.5:1 이상, 색만으로 구분 금지, 최소 글자 14px.

## 9. 추천 결정 (내용·구성 변경 포함)

1. **1인 앱 3종은 한 장으로 축약.** 한국사·Noahlog·말씀나무는 "혼자 끝까지 출시했다"는 증거가 핵심이므로 화면 1장 + 과제 1개면 충분. 깊이는 업무 프로젝트와 RAG에 배분.
2. **프로젝트 순서를 직무 관련도 순으로.** 로컬 AI → KD order → 수직농장 → RAG 챗봇 → LingoStep → 1인 앱 3종. AI 역량을 앞에, 운영 경험을 뒤에.
3. **"한눈에" 장을 신설하고 소개 장은 없앤다.** 지금 소개 장의 자기소개 문단은 이력서와 중복. 숫자 4개와 역량 3개로 대체.
4. **"일하는 방식" 장 신설.** 업무 문서 3개에 공통으로 나타난 패턴(UX 문서 선행, 결정 요청서로 현업 확인, 시각 회귀·EXCEPT 비교로 "같은 답" 증명, 조용한 실패를 시끄럽게)을 4개 카드로. 팀에서 어떻게 일하는지 보여 주는 장이 지금은 없음.
5. **프로젝트 인덱스를 표 대신 카드 그리드로.** 썸네일이 있어야 30초 독자가 기억함.
6. **역할 바 도입.** 팀 프로젝트는 "내 담당 / 팀 담당"을 시각적으로. 정직한 표기가 신뢰를 만든다.
7. **KPI 타일로 수치 분리.** 22.9초 → 0.12초, 68 → 0건, 855 → 402줄, 3,000ms → 50ms 같은 수치를 본문에서 꺼내 크게.
8. **강조색은 파란색 유지.** 이력서와 같은 색으로 두 문서가 한 세트로 보이게.
9. **헤더는 한글 우선, 영문은 보조.** "PROJECTS" 같은 영문 대제목은 표지·마무리에만.
10. **표지 포지셔닝 문장 추가.** 이름 아래에 "앱 4종을 혼자 출시하고, 지금은 로컬 LLM·업무 시스템·스마트팜 화면을 만듭니다" 한 줄.
